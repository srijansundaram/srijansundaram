# 🚀 Featured Project

## 🛡️ DeepShield — AI Deepfake Detection Platform

Production-grade multimedia forensic platform capable of detecting face-swap, GAN-generated and diffusion-generated deepfakes using a calibrated ensemble of deep learning models.

### Highlights

- 🤖 XceptionNet + EfficientNet-B4 + Vision Transformer Ensemble
- 🎥 Image, Video, Webcam & Batch Detection
- 🔍 Grad-CAM Explainability
- 🧠 Audio-Visual Lip Sync Detection
- 📊 FFT & Metadata Forensics
- ⚡ FastAPI REST API
- 📄 Automated Forensic PDF Reports

**Tech**

Python • PyTorch • FastAPI • OpenCV • Streamlit • InsightFace

👉 https://github.com/srijansundaram/DeepShield
